# 🎓 MyClass - Classroom Management Portal

## 📌 Project Overview

MyClass is a classroom management web application that allows faculty and students to communicate efficiently. Faculty can post announcements, upload study materials, and manage classroom content, while students can view announcements and access shared files.

---

## 🚀 Features

### 👨‍🏫 Faculty

* Secure Login Authentication
* Post Announcements
* Delete Announcements
* Upload Study Materials
* Delete Files

### 👨‍🎓 Students

* Secure Login Authentication
* View Announcements
* Access Uploaded Files

### 🔐 Security

* JWT Authentication
* Role-Based Access Control (Faculty / Student)
